## 2026-08-16 - Omit Unused Article Content Column in News List Queries
**Learning:** In list and card views (`/api/news`, `/api/news/category/:category`, `/api/news/search`), querying `.select('*')` returns the full unstructured article `content` text across every item in the dataset. Because news cards and search listings only display metadata (`title`, `slug`, `description`, `image_url`, `category`, `author`, `created_at`), transmitting `content` significantly inflates database egress bandwidth, serialization overhead, and API network response payloads without any consumer benefit on the client.
**Action:** When creating or modifying listing endpoints in Supabase or SQL models, define and project an explicit subset of list fields (excluding large body/content columns), and reserve full-body fetches strictly for single-record detail routes (`/api/news/:slug`).
