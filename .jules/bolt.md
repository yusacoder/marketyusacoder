## 2025-05-10 - Supabase List Queries Payload Optimization & Navigation Caching
**Learning:** Returning full article `content` text in list queries (`getAllNews`, `getNewsByCategory`, `searchNews`) inflates network payload and database execution size for list pages when cards only render summary metadata. Restricting select fields to `NEWS_LIST_FIELDS` (`id, title, slug, description, image_url, category, author, created_at`) reduces payload transfer significantly. Additionally, static category navigation data fetched on every page load can be safely cached in `sessionStorage` to completely eliminate duplicate HTTP roundtrips.
**Action:** Always project specific list fields in database query controllers for summary/list endpoints and leverage client-side session caching for static/rarely-changing navigation endpoints.
